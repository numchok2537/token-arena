# อัปเดตกลไกเกมใหม่ (แบบให้/ริบข้ามคน) — ใช้ครั้งเดียว ~2 นาที

เนื่องจากเปลี่ยนกลไกเกม (จากกดปรับ Token ของตัวเองอย่างเดียว เป็นเลือกให้/ริบข้ามคนได้ พร้อมหน้าสรุปผล) ต้องอัปเดตโค้ดฝั่งเซิร์ฟเวอร์ (Apps Script) ด้วยครับ **ไม่ต้องสร้างโปรเจกต์ใหม่ ไม่ต้องเปลี่ยนลิงก์** ทำตามนี้:

1. เปิดโปรเจกต์ Apps Script เดิมที่เคยตั้งค่าไว้ (script.google.com → เปิดโปรเจกต์ที่ชื่อ "Token Arena" หรือชื่อที่ตั้งไว้)
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้งทั้งหมด แล้ววางโค้ดใหม่จากไฟล์ `apps-script/Code.gs` ที่แนบมาลงไปแทน
3. กด **บันทึก** (ไอคอนแผ่นดิสก์)
4. กด **ทำให้ใช้งานได้ (Deploy) → จัดการการทำให้ใช้งานได้ (Manage deployments)**
5. กดไอคอนดินสอ (แก้ไข) ข้างการทำให้ใช้งานได้ที่มีอยู่แล้ว
6. ตรงช่อง **Version** เปลี่ยนจาก "..." เป็น **"New version" (เวอร์ชันใหม่)**
7. กด **Deploy**

**ลิงก์ Web App จะเหมือนเดิมทุกประการ** ไม่ต้องเปลี่ยนอะไรในเว็บอีกฝั่งเลยครับ พอทำเสร็จเปิดเว็บใหม่แล้วใช้กลไกให้/ริบข้ามคนได้ทันที
