# ตั้งค่าระบบ Token แบบเรียลไทม์ (ใช้ครั้งเดียว ~5 นาที)

ครั้งนี้ไม่ต้องสร้าง Google Sheet เลยครับ ใช้ Apps Script เปล่าๆ เก็บข้อมูลในตัวมันเอง

1. เปิด [script.google.com](https://script.google.com) → กด **โปรเจกต์ใหม่ (New project)**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดจากไฟล์ `apps-script/Code.gs` ในโปรเจกต์นี้ลงไปแทน
3. กด **บันทึก** (ไอคอนแผ่นดิสก์) — ตั้งชื่อโปรเจกต์อะไรก็ได้ เช่น "Token Arena"
4. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**
   - กดไอคอนเฟือง ข้าง "Select type" → เลือก **เว็บแอป (Web app)**
   - Execute as: **Me (บัญชีของฉัน)**
   - Who has access: **Anyone (ทุกคน)**
   - กด **Deploy**
5. ครั้งแรกจะมีหน้าต่างขอสิทธิ์ — เลือกบัญชี Google ของอาจารย์ → กด "Advanced" → "Go to (ชื่อโปรเจกต์) (unsafe)" → Allow (ปลอดภัย เพราะเป็นสคริปต์ที่อาจารย์เพิ่งวางเอง)
6. คัดลอกลิงก์ **Web app URL** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)
7. เปิดไฟล์ `js/config.js` วาง URL นั้นลงใน `API_URL`

เสร็จแล้วครับ เพื่อนทุกคนที่เปิดเว็บนี้จากมือถือ/คอมของตัวเอง จะเห็น Token ของทุกคนอัปเดตพร้อมกัน (รีเฟรชข้อมูลทุก 2 วินาที)

**ถ้าอยากเริ่มเกมใหม่** กดปุ่ม "เริ่มเกมใหม่ (ล้างผู้เล่นทั้งหมด)" ในหน้าเว็บได้เลย ไม่ต้องกลับมาที่นี่
